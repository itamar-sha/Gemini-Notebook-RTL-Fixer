# Gemini Notebok RTL Fixer

סקריפט שמסדר את הכיוון של טקסט בעברית בתשובות של Gemini Notebook. 

לא השקעתי בזה יותר מדי מחשבה אז אם משהו נשבר אני לא לוקח אחריות על זה 💀

**איך מתקינים?**
1. משכפלים את הREPO

2. נכנסים בדפדפן לכתובת `chrome://extensions` ומדליקים את המתג של **Developer mode** בפינה העליונה.

3. לוחצים על **Load unpacked** ובוחרים את התיקייה ששוכפלה.

זהו. אם עובד לכם - מעולה. אם לא, באסה
